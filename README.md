A single-line cat joke in a tight setup-and-turn shape: a vet delivers one blunt
diagnosis, the cat fires back a diagnosis of the vet's whole worldview, and the
closing beat flips who actually wins the appointment. The turn depends on the
angry one-liner being so good it earns a repeat visit — the punchline pays off
the cat's indignation instead of explaining it. No tables, boxes, lasers, or
"can has" in sight; just one spot of surgical petty revenge.

## Run it

```sh
node main.ts
```

Writes the joke to `/output/entry.txt` (override with a positional directory
argument or the `MAKEFUN_OUTPUT_DIR` environment variable).

```sh
node main.ts --help
```

Prints usage and exits 0.
